# DENDY OS — Personal Automotive Operating System
### Разработано для Omoda C5 (2023 1.6 Turbo AWD)

DENDY OS — это персональная автомобильная мультимедийная система с собственным минималистичным интерфейсом (в стиле Apple/Tesla/Rivian), встроенным искусственным интеллектом DENDY AI и адаптацией под широкоформатный дисплей Omoda C5 (1920x720).

## Быстрый старт

Проект построен на современном Android-стеке:
- **Язык**: Kotlin 1.9
- **UI Toolkit**: Jetpack Compose & Material 3
- **Архитектура**: Modular Clean Architecture + MVI/StateFlow
- **Мультимедиа**: Media3 / MediaSession
- **AI**: DENDY Assistant Engine (поддержка русского, казахского и английского языков)

Подробное описание архитектуры и инструкция по установке в автомобиль находятся в [docs/ARCHITECTURE_AND_OMODA_SPEC.md](docs/ARCHITECTURE_AND_OMODA_SPEC.md).
