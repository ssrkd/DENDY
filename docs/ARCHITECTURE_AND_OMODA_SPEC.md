# DENDY OS — Архитектурная и техническая спецификация
## Мультимедийная система для Omoda C5 (2023, 1.6 Turbo AWD)

---

### 1. Результаты технического исследования штатного ГУ Omoda C5

| Параметр | Фактическое значение на Omoda C5 (2023) | Примечания для DENDY OS |
| :--- | :--- | :--- |
| **Платформа / SoC** | MediaTek MT8666 / UNISOC UIS7862 (8-core, ARM64) | 4GB RAM / 64GB eMMC. Высокая производительность для Compose. |
| **Операционная система** | Android 9.0 (Pie, API 28) / Android 10 (API 29) | Модифицированный AOSP от Chery / Neusoft Automotive. |
| **Дисплей мультимедиа** | 10.25" (или 12.3" в топовых версиях) | Разрешение **1920x720** (или 1280x720 scaled), соотношение 8:3. |
| **Установка сторонних APK** | Заблокирована в пользовательском меню | Доступ через Инженерное меню (коды `8888`, `202088`, `*#*#3646633#*#*`) либо ADB по USB/Wi-Fi. |
| **Взаимодействие с CAN-шиной** | Через внутренний MCU шлюз и OEM сервис | Прямой доступ к raw CAN из APK закрыт песочницей Android. |

#### Политика безопасности и невмешательства в CAN:
- **Критически важные системы**: ЭБУ двигателя (ECU), коробка передач (7DCT), тормозная система (ABS/ESP), полный привод (AWD Torque Vectoring) и подушки безопасности изолированы.
- **DENDY OS работает в режиме Android Launcher**: чтение безопасных данных (одометр, TPMS, климат через вендорные бродкасты/провайдеры) без перепрошивки ROM.

```
    ├── music/            # Полноэкранный музыкальный центр
    ├── apps/             # Лаунчер установленных приложений

```

### 3. Статус функций: боевые vs демонстрационные

| Модуль | Функция | Статус | Как работает |
| :--- | :--- | :--- | :--- |
| **Launcher** | Запуск вместо стокового экрана | **Боевая** | `category.HOME` и `priority=1` в `AndroidManifest.xml`. |
| **Автозапуск** | Запуск при включении зажигания | **Боевая** | `BootCompletedReceiver` слушает `BOOT_COMPLETED` и `QUICKBOOT_POWERON`. |
| **Дизайн-система** | Светлая/Темная автомобильная тема | **Боевая** | Jetpack Compose, Apple/Rivian-стиль, стекло, крупные кнопки 56dp+. |
| **Музыка** | Воспроизведение, перемотка, плейлист | **Боевая** | Реактивный стейт, тикер таймкодов, интеграция с Android Media3. |
| **DENDY AI** | Распознавание команд RU/KZ/EN | **Боевая** | Парсинг интентов климата, шин, музыки, режимов движения. |
| **DENDY AI** | Внешняя генеративная LLM | **Демо** | Подготовлен интерфейс для подключения Gemini / OpenAI API. |
| **Vehicle TPMS** | Отображение давления 4 колес | **Гибрид** | Автоопределение вендорного сервиса Chery; в dev-режиме — симуляция. |
| **Климат** | Регулировка температуры и обдува | **Гибрид** | UI и стейт боевые; проброс команд в OEM-сервис через Reflection. |
| **Навигация** | Картографический рендер | **Демо** | Готовая карточка маршрута и маневров для встраивания Яндекс/Mapbox SDK. |

### 4. Инструкция по развертыванию на автомобиле Omoda C5

1. **Сборка APK**:
   ```bash
   ./gradlew :app:assembleRelease
   ```
2. **Активация режима разработчика на ГУ**:
   - В настройках мультимедиа перейти в *«О системе»* (*About*).
   - Тапнуть 7 раз по версии ПО / номеру сборки до появления сообщения об открытии доступа.
   - При запросе пин-кода ввести сервисный пароль Omoda: `8888` или `202088`.
   - Включить переключатель *«Отладка по USB (USB Debugging)»*.
3. **Установка по ADB**:
   - Подключить ноутбук через USB-порт (Data port в центральной консоли Omoda C5):
   ```bash
   adb devices
   adb install -r app-release.apk
   ```
4. **Выбор по умолчанию**:
   - Нажать физическую сенсорную кнопку «Home».
   - Выбрать **DENDY OS** и нажать **«Всегда» (Always)**.
