# DENDY OS — APK Repository for Omoda C5 (2023)

В эту папку помещаются оригинальные Android APK-файлы для установки в мультимедиа головного устройства **Omoda C5 (Android 9/10, дисплей 10,25″, 1920×720 px)**:

## Рекомендуемый пакет приложений (Казахстан):

1. **`2gis.apk`** — 2ГИС Навигатор
   * Скачать официальный APK: [apk.2gis.ru/2gis.apk](https://apk.2gis.ru/2gis.apk)
   * Поддерживает полную загрузку офлайн-карт Астаны и всего Казахстана, скоростные камеры Сергеек.

2. **`yandexmaps.apk`** — Яндекс Карты
   * Скачать официальный APK: с сайта [m.yandex.ru](https://m.yandex.ru) или RuStore
   * Пробки, навигация, дорожные события.

3. **`yandexmusic.apk`** — Яндекс Музыка (с полноценной «Моей волной»)
   * Скачать официальный APK: [rustore.ru](https://rustore.ru)
   * Настоящая «Моя волна», фоновое воспроизведение в машине, сохранение треков в память автомобиля.

## Способы установки в автомобиль Omoda C5:

### Способ 1: Через USB-флешку (Самый простой)
1. Скопируйте скачанные `.apk` файлы на любую обычную USB-флешку в папку `DENDY/apks/`.
2. Вставьте флешку в USB-порт Omoda C5 (под центральной консолью).
3. В лаунчере DENDY OS откройте раздел **«Приложения & APK Store»** и нажмите кнопку **«Обзор USB флешки»**.
4. Нажмите **«Установить»** напротив каждого приложения.

### Способ 2: Вшивание в дистрибутив DENDY Launcher
* Поместите файлы `.apk` в `app/src/main/assets/apks/`.
* При первой установке DENDY OS на головное устройство модуль `DendyPackageInstaller` автоматически распакует и установит их в фоновом режиме.
